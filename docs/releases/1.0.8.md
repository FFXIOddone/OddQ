# OddQ v1.0.8

The main Browser/Guide window can now be resized below OddQ's previous minimum.
Switching views keeps the size you chose instead of restoring the default size.
Initial defaults and the existing maximum dimensions remain unchanged. ImGui's
native minimum still applies. Very small windows may clip content; enlarge the
window to access all controls.

Thanks to **@kimeids on Discord** for requesting this patch!

This patch is based exclusively on v1.0.7. All guide and bundled data files are
unchanged. The ongoing guide review is separate and is not included.

Install by replacing `Ashita/addons/oddq` with the folder from the release ZIP,
then reload OddQ. Keep your current version if you want to roll back.

Validation: focused mocked-ImGui window behavior checks, LuaJIT compilation of
all 42 runtime Lua files, exact package/source comparison, and manifest/checksum
verification. No in-game validation is claimed.
